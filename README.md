# Weather App 🌤️

A simple weather application built using Python and Flask.

## Features

- Search weather by city
- Uses OpenWeatherMap API
- Shows temperature
- Shows weather condition and description
- Shows weather icon
- Responsive UI using Bootstrap

## Technologies Used

- Python
- Flask
- Requests
- OpenWeatherMap API
- Bootstrap
- HTML/CSS
